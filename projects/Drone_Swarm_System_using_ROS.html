Drone Swarm System using ROS

Technology / Tools

Python, ROS, Gazebo and C++.

Description

In this project, we have developed a decentralized system of autonomous multi-rotors using robot operating system (ROS). The project is developed using nature inspired algorithms. Multiple lab experiments in gazebo simulator and field experiment have been performed to evaluate the performance. We concluded that this system can perform tasks like area scanning efficiently and collaboratively.
