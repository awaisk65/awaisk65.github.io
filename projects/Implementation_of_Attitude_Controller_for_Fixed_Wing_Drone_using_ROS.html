Implementation of Attitude Controller for Fixed Wing Drone using ROS

Technology / Tools

Python, ROS and Gazebo.

Description

In this project, an attitude controller is designed for the fixed-wing drone. The purpose of the project is to fly the fixed-wing drone autonomously using different type of algorithms, for example, nature inspired algorithms (i.e., flocking, particle swarm optimization). Multiple successful trials have been conducted in the gazebo9 simulator.
