Thesis Title

Anomaly Detection and Localization in Internet of Forest Things (IoFT).

Description

This thesis targets on securing IoFT device and forestry monitoring. A machine learning approach is used to detect any anomaly in the smart forest and localize it. Using received signal strength indicator (RSSI) values to generate unique fingerprints for each controller. Implemented an algorithm to send these unique pack- ets to a server for decoding and path identification. Successfully trained a machine learning model on the server to classify and detect potential attacks, ensuring robust security for the IoFT infrastructure.
